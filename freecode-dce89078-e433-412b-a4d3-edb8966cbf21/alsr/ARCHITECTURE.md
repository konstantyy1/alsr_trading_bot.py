# Архітектура

```
cron-job.org (кожні 5 хв, POST /api/scan)
            │
            ▼
        Render (gunicorn, 1 worker, WSGI)
            │
   ┌────────┴─────────┐
   ▼                  ▼
 bot/web.py       bot/scan.py ──── run_scan()
 (WSGI-роутер)         │
   │                   ├─ datafeed.py    Yahoo M5/M15/H1/H4 (+ H4 агрегація)
   │                   ├─ analysis.py    свинги, BOS/CHoCH, FVG, ATR, RSI, PDH/PDL
   │                   ├─ signals.py     5 сетапів, score, фільтри ризику
   │                   ├─ lifecycle.py   READY→ACTIVE→TP/SL на закритих M5
   │                   ├─ newsfeed.py    календар + ECB/Fed/BLS RSS
   │                   ├─ markettime.py  IANA-зони, сесії, новинне вікно
   │                   └─ store.py       Postgres / SQLite
   │
   ├─ /                 дашборд (template.html)
   ├─ /health           публічний
   ├─ /api/*            Bearer / ?token / cookie
   └─ /telegram/<secret> команди бота (X-Telegram-Bot-Api-Secret-Token)
```

## Потік одного сканування
1. Отримати snapshot ціни й свічок, перевірити свіжість, дублікати, пропуски.
2. Оновити відкриті сигнали на закритих свічках (консервативно при неоднозначності).
3. Завантажити календар і офіційні RSS, зберегти події.
4. Порахувати новинний ризик (NONE / ELEVATED / BLOCKED).
5. Перевірити ліміти: ризик дня, кількість сигналів, відкриті сценарії, волатильність.
6. Знайти сетапи, оцінити score, відсіяти слабкі.
7. Зберегти сигнал **до** відправки, потім надіслати (дедуплікація за ключем).

## Ключові рішення
- **Без Flask.** Чистий WSGI на стандартній бібліотеці: gunicorn запускає так само,
  але кожен маршрут можна перевірити без встановлення залежностей.
- **Стан у БД, не в памʼяті.** Render free засинає і перезапускається.
- **Сигнал зберігається перед відправкою.** Збій Telegram не створює дубль.
- **H4 з H1.** Yahoo не має нативного 4h.
- **Сесії з IANA-зон.** Жодних статичних UTC-офсетів; перехід на літній час
  перевірено тестом.

## Модулі
| Файл | Відповідальність |
|---|---|
| `config.py` | конфігурація з env, ліміти ризику |
| `datafeed.py` | провайдер, валідація свічок, агрегація H4 |
| `analysis.py` | структура ринку, FVG, рівні дня/тижня |
| `signals.py` | сетапи, score, `evaluate()` |
| `lifecycle.py` | TP/SL на закритих M5 |
| `markettime.py` | зони, сесії, killzone, новинне вікно |
| `newsfeed.py` | календар і офіційні RSS |
| `notify.py` | формат повідомлень, Telegram API |
| `scan.py` | оркестрація циклу |
| `commands.py` | команди бота |
| `store.py` | Postgres/SQLite, дедуплікація, стан |
| `api.py` | JSON-payload для дашборду |
| `web.py` | WSGI-роутер, авторизація |
| `selftest.py` | 21 детермінована перевірка |
| `template.html` | дашборд |
